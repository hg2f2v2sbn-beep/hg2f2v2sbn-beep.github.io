- 배치: 평생사주·사주궁합 아래, AI 친구 카드 위, 가로 전체 너비. 클릭 시 기존 신살·귀인 화면(`THEMES.shinsal`)으로 연결. 사주 입력은 그 화면의 기존 절차를 그대로 탄다.

- 평생사주 카드: 기존 토끼 그림(`extra_02_rabbit.webp`)을 첨부된 고양이 그림(`product-saju.webp`)으로 교체.
